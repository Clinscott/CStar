# CStar Architecture Archive

CStar is preserved as an inactive historical subsystem. Corvus Organism is the
current estate control and workflow plane. References in retained source and
documents to CStar ownership, authority, routing, lifecycle, or runtime describe
the retired design and grant no present capability or permission.

The archive keeps its deterministic kernel, Hall/PennyOne persistence,
host-integration generators, Forge history, and validation suites so migrations
can be reviewed against original behavior. All automatic host discovery
surfaces in this repository are intentionally inert.

Development validation is source evidence only. It is separate from host
installation, activation, runtime acceptance, lifecycle acceptance, deployment,
production, and publication.
