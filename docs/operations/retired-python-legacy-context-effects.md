# Retired Python Legacy Context Effects

The TypeScript CStar kernel and host-native workflow own current context,
lifecycle, routing, and implementation. Four historical Python families are
bounded compatibility surfaces:

- `SovereignContext` fails with
  `legacy_python_context_effect_surface_retired_use_cstar_kernel` before
  feedback-file reads, persona/HUD mutation, trace compilation, callbacks, or
  teardown work. `parse_feedback_context` accepts explicit JSONL strings only.
- `Cortex` fails with
  `legacy_python_cortex_runtime_retired_use_bounded_cstar_hall_search` before
  project-document discovery, polling, ingestion, or search. Use
  bounded CStar Hall search for current estate context. `parse_cortex_sections`
  is a pure,
  byte-bounded transform over caller-supplied text.
- The old `engine.bifrost.SkillForge` keeps only its inert empty analysis shape.
  Failure-log and generated-source actions fail with
  `legacy_python_skill_forge_effect_retired_use_cstar_forge`; implementation
  uses the durable `cstar_forge_request -> cstar_forge_authorize -> cstar_forge_execute` lifecycle.
- `VectorIngest` may update only the concrete process-local detached `MemoryDB`
  helper. Directory discovery and the adjacent `SovereignBuilder` fail with
  `legacy_python_skill_directory_scan_retired_use_cstar_skill_registry` before
  inspecting a path. `parse_skill_intent` accepts explicit text only.
- Historical fishtest, profiler, diagnostic, collision, correction-overfit, and
  trace-engine builders fail with
  `legacy_python_vector_scan_caller_retired_use_cstar_validation` before
  dataset, directory, vector, report, or correction effects. The detached
  `MetaLearner` analysis remains available, but its file-backed tuner and apply
  actions fail with
  `legacy_python_weight_tuner_effect_retired_use_cstar_validation`.

None of these surfaces grants routing, execution, validation, persistence, or
promotion authority. Their pure outputs are detached metadata and evidence.
