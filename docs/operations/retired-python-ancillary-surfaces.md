# Retired Python Ancillary Surfaces

The Python modules listed below are import-compatible tombstones. They are not
supported CStar execution paths and must not be restored as fallbacks.

## Current contract

- Skill discovery, installation, and generation do not run through
  `install_skill.py`, `skill_forge.py`, Wild Hunt, or `acquire.py`.
- Research, source collection, and model calls do not run through Evolution Watch,
  the Taliesin wrapper, the user-style extractor, Danger Room, or Utility Belt.
- CStar lifecycle and memory state do not run through Synapse, semantic-memory
  bootstrap, QMD projection, autonomous scout queues, Python HTTP telemetry, or
  direct local databases.
- Repository validation and maintenance do not run through the Archive Consolidator,
  Perimeter Sweep, Network Watcher, Overwatch, or source-rewriting repair scripts.
- The Bifrost code sanitizer retains pure AST, syntax, text-normalization, and
  classification helpers. Live documentation enrichment returns no result, and
  its QMD source writer fails closed.

Action methods return a stable no-effect value or raise a stable retirement error.
Imports do not load environment files, credentials, provider clients,
network clients, or databases. They do not start subprocesses or loops, inspect
other spokes, mutate source, install skills, write Hall state, or perform Git.

## Supported routes

- Use CStar kernel tools for bead lifecycle, result recording, telemetry
  summaries, state projections, and on-demand deterministic wardens.
- Use Researcher for authorized evidence gathering and source collection.
- Use the durable CStar Forge request and execute path for implementation.
- Use the supported host skill installation surface only inside its separately
  authorized installation window.
- Apply source changes as bounded reviewed patches with focused tests.

Historical campaign ledgers and development journals describe the retired
implementations. They are evidence of past behavior, not current authority.
