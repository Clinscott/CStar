# Retired ANS, Ceremony, and PennyOne Proxy

The former autonomic wake/sleep API, startup ceremony, and PennyOne HTTP/
WebSocket proxy are compatibility tombstones. They fail before process, timer,
network, filesystem, Hall, StateRegistry, provider, source, or callback effects.

Use `cstar_status` for bounded status, `cstar_doctor` for health, and named
`cstar-kernel` MCP tools for lifecycle and PennyOne projections. CStar does not
write or expose a visualization bearer token and a visualization client grants
no dispatch authority.
