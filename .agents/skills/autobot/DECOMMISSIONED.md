# AutoBot public surface - decommissioned

This directory intentionally has no `SKILL.md`. AutoBot is not a discoverable
host skill, registry capability, MCP tool, queue worker, or provider route.

The scripts remain only as fail-closed tombstones for stale callers. They do
not read targets, enqueue or claim work, invoke Hermes, spend, or write output.
Do not register this directory as a skill or invoke the scripts directly.

Historical implementation remains in repository lineage for forensic review.
It grants no current authority and cannot be reactivated by a CStar packet,
receipt, registry entry, environment flag, or callback.
