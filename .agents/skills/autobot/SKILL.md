# AutoBot retired

Public AutoBot delegation is decommissioned and cannot be activated. The files
retained in this directory are compatibility tombstones only and always fail
with the historical compatibility identifier
`legacy_autobot_retired_use_cstar_forge`. That identifier is evidence of the
retired route; it does not make Forge actionable.

Forge is `TOMBSTONED_PERMANENT`. The supported Corvus implementation route is:

`authorized Bead/SET -> cstar_mission -> deterministic runner effect -> native
task-control work cell -> independent cstar_record_result`

Worker output remains unverified evidence until independent validation is
recorded through `cstar_record_result`.
