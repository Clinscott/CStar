# Public Hermes daemon lane decommissioned

Every executable in this directory is a fail-closed compatibility tombstone.
The former FIFO daemons could start unmanaged model processes, read credentials,
perform research, and write spoke/wiki state outside CStar.

- Implementation: `cstar_forge_request -> cstar_forge_execute ->` private
  Hermes `cstar-hub` adapter, followed by independent validation.
- Research: authorized Researcher source lanes with bounded receipts.

Do not restore these scripts as a fallback.
